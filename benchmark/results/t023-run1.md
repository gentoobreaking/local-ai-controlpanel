## 關鍵發現（本輪新修正，供 T024 沿用）

1. **Artifact Gate 以「內容級最小 diff」驗證（新增 `canonicalizeDiff`）**：模型常整檔重 emit、hunk 行號錯、重複新增已存在內容；現在先把 raw patch 容忍式套到 scratch copy，再 `git diff --no-index` 重產真實變更——垃圾消散，tests/ 若無實質改動即不觸發 readonly。
2. **Ground-truth tests 保護**：`tests/test_api_client.py` readonly（新增測試可開新檔 `tests/test_extra.py`）；模型 3 組 run 都試著加自己的測試進基準檔 → gate 拒絕 → 回饋重試，最終只改 `src/`。
3. **Gate 拒絕現在走回饋重試**（與驗證失敗同迴圈），不再硬性終止 task。
4. **模型選擇**：`qwen2.5-coder:7b` 在「不可改 tests」約束下 4/4 全滅（2 次 run 各 4 attempts）；`robit/ornith:9b`（§40 正列）2 attempts 過。9B 為本地基準下限。
5. **lint=FAIL 屬 style 級**（F401 函式內 import）：不進 §40 gate；重試迴圈可再帶 lint 回饋一輪修掉。
6. **event log**：ON=9 筆、OFF=15 筆（含 3 輪 research retry + reflection），並存完整 e2e.db。
